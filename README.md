# c9n-ext-media

ffmpeg und Medienwerkzeuge als optionale c9n-Erweiterung (Video, Audio).

Erweiterung für [c9n](https://github.com/dajor/c9n-app). Sie wird getrennt vom c9n-Kern gebaut und versioniert. Eine c9n-Version trägt in ihrer `release.json` ein, welcher Stand dieser Erweiterung (mit Prüfsumme) dazu passt. Es wird nichts frei aus dem Netz nachgeladen.

Status: angelegt, noch leer. Der Inhalt zieht aus `c9n-app/deploy/Dockerfile` hierher um (siehe Plan „Image verkleinern“).
